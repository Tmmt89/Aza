# Ресурсы приложения

- `chechen-lexicon.tsv` — частотный словарь чеченских слов, собран конвейером
  `Tools/BuildChechenLexicon` из корпуса `lingtrain/chechen-russian`.
  Формат: `слово\tчастота\tфлаг «только с заглавной»`, кодировка UTF-8,
  палочка канонизирована к U+04CF.

✅ **Лицензия:** автор корпуса (lingtrain) дал разрешение на использование
для создания и распространения частотного словаря в составе Aza
(подтверждено владельцем проекта 25.08.2026). Источник указывается в
разделе «О приложении» и в THIRD_PARTY при релизе.

✅ **Второй источник — `laamxo/dosham`** (классические словари: Мациев,
Байсултанов, Исмаилов, анатомический терминологический; только ce→ru
направление, 5 904 заголовочных слова, boost ×3): ✅ **автор дал одобрение**
на использование в Aza (подтверждено владельцем проекта 25.08.2026).
Aza не занимается переводом и не конкурирует со словарём — используется
только список заголовочных слов для коррекции раскладки и опечаток.
Атрибуцию компиляции и десяти исходных словарей добавить в THIRD_PARTY при релизе.

✅ **Третий источник — Чеченская Википедия** (`wikimedia/wikipedia`,
конфиг `20231101.ce`, ревизия b04c8d1c…): 12 000 статей с кириллическими
заголовками и полным текстом ≥ 800 символов (бот-стабы отфильтрованы,
импортёр — `Tools/import_wikipedia.py`). Лицензия **CC BY-SA 4.0**:
при релизе обязательна атрибуция «Часть данных словаря получена из
Чеченской Википедии (CC BY-SA)» в разделе «О приложении» / THIRD_PARTY.

✅ **Четвёртый источник — `NM-development/nmd-ce-ru-171k-v0`** (ревизия
aa2910a0…, колонка ce, 171 224 пары, maxShare 0.2): опубликован под
**MIT** авторами открытой системы перевода для чеченского
(arXiv:2507.12672, Umishov & Grigorian). Состав по колонке source:
словарь Мациева (91k), переводы Корана и Библии, GATITOS (бытовая
лексика Google), компьютерный и анатомический терминологические словари,
фразы baltoslav.eu, новости. Провенанс классических словарей — тот же
класс, что у уже одобренного dosham (Мациев входит в оба); MIT-декларация
издателя датасета зафиксирована, при релизе атрибутировать в THIRD_PARTY.
Импорт: `python3 Tools/export_corpus.py datasets/nmd-ce-ru.parquet
datasets/nmd_corpus.txt ce`.

**Русский фильтр** (`Resources/russian-words.txt`): только слова с
русской частотой ≥500 из pyspellchecker (3 009 слов; хвост списка —
мусорные строки, совпадающие с чеченскими словами). Слова фильтра с
взвешенной чеченской частотой ≥ `russianKeepMinCount` (100) остаются —
это реальные заимствования и омографы (со, ду, миллион, машина); полный
аудит-список — `rescuedFromRussianFilter` в manifest.json.

**Персональный разговорный корпус** (рекомендуется владельцу): открытых
корпусов чат-регистра для чеченского нет (текстинговые формы вроде «ху»
вместо «хӏун» отсутствуют во всех источниках). Решение — локальный
личный корпус: экспортируйте свои чаты (Telegram: Настройки → Экспорт
данных → machine-readable JSON; извлеките тексты своих чеченских
сообщений в текстовый файл) в `datasets/personal-corpus.txt` (папка
gitignored — файл никогда не попадёт в git) и добавьте источник в
config.json:

```json
{
  "id": "personal",
  "url": "datasets/personal-corpus.txt",
  "revision": "local-personal-corpus",
  "columnIndex": null,
  "hasHeader": false,
  "maxShare": 0.1
}
```

Пересоберите словарь — ваши разговорные формы войдут с реальными
частотами. Всё локально, ничего не покидает машину.

Итог: 63 601 слово, 1,4 МБ, покрытие held-out 98,1%.

Пересборка после обновления корпуса:

```bash
cd Tools/BuildChechenLexicon
swift run BuildChechenLexicon build --config config.json --out out_lexicon
cp out_lexicon/lexicon.tsv ../../Aza/Resources/chechen-lexicon.tsv
```
