# Aza

Нативный локальный помощник для macOS, который живёт вокруг выреза экрана.

## Запуск прототипа

```bash
swift run Aza
```

Проверка логики без открытия интерфейса:

```bash
swift run Aza --self-check
```

## Расписания намаза

Aza поддерживает локальный каталог `Sources/Aza/Resources/prayer-schedules-2026.json`. Сам каталог не входит в публичный репозиторий, пока не подтверждены права на его распространение. Без него приложение собирается и показывает состояние «Нет данных».

Для полноценного приложения, подписи и DMG понадобится Xcode. Текущая Swift Package-сборка предназначена для разработки интерфейса и системных прототипов.

Спецификация продукта: [PRODUCT_SPEC.md](PRODUCT_SPEC.md).
