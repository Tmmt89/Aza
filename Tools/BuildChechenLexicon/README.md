# BuildChechenLexicon — офлайн-конвейер сборки чеченского лексикона

Инструмент НЕ входит в приложение Aza. Запускается вручную; готовый артефакт
(`lexicon.tsv` + `manifest.json`) коммитится как ресурс приложения.

## Логика конвейера

1. **Загрузка.** Датасеты тянутся с HuggingFace по resolve-URL с закреплённой
   ревизией (хеш коммита), не по имени ветки — иначе сборка невоспроизводима.
2. **Отбор.** Только чеченская сторона: колонка `ce` параллельного корпуса
   (`columnIndex`) и/или монолингвальные тексты.
3. **Токенизация.** Границы слова — не-буквы, НО `1` внутри кириллического
   слова не граница (подмена палочки); латинские `I`/`l` — буквы и так
   остаются в словах.
4. **Канонизация корпуса.** Все подмены (`1`, `I`, `l`) И обе кодовые точки
   палочки (заглавная U+04C0, строчная U+04CF) приводятся к одной канонической
   форме U+04CF; частоты вариантов складываются. Без этого в словаре будут
   дубли «г1ала» / «гӀала».
5. **Регистр.** Формы в нижнем регистре; флаг `capitalOnly` отделяет вероятные
   имена собственные (их автокоррекция не трогает).
6. **Отсев мусора.** Слова ниже `minCount` (по умолчанию 2–3) выбрасываются;
   всё с латиницей/цифрами/символами отбраковывается.
7. **Взвешивание источников.** Каждому источнику задаётся `maxShare` — потолок
   его доли в итоговых частотах, чтобы Писания не задавили бытовую лексику.

## Использование

```bash
cd Tools/BuildChechenLexicon

# 1. Заполнить config.json реальными датасетами и ЗАКРЕПИТЬ ревизии (sha).
cp config.example.json config.json

# 2. Сборка словаря.
swift run BuildChechenLexicon build --config config.json --out ../../Resources/Lexicon

# 3. ТОЧКА GO/NO-GO: покрытие бытового текста ≥ 70%.
swift run BuildChechenLexicon coverage \
  --lexicon ../../Resources/Lexicon/lexicon.tsv \
  --eval heldout_news.txt heldout_prose.txt
```

Кэш загрузок: `~/.cache/AzaChechenLexicon`. Каталог `.build` в git не добавлять.

## Тесты

```bash
swift test
```

Покрывают: склейку подмен палочки при токенизации, канонизацию обоих кодовых
пунктов палочки, склейку дублей с разных написаний, отсев по minCount,
флаг capitalOnly, фильтрацию латиницы, ограничение доли источника,
распознавание входа с подменами через coverage.
