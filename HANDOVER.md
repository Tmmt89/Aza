## 1. Что такое Aza

Aza (от чеченского «голос») — бесплатное open-source нативное macOS-приложение,
живущее вокруг выреза MacBook (Dynamic Island) и объединяющее четыре функции:

1. время намаза;
2. локальный голосовой ввод (Whisper/WhisperKit, всё локально);
3. автопереключение русской / английской / чеченской раскладок;
4. интеллектуальная история буфера обмена.

Ключевые принципы: **всё локально** (никакой телеметрии, облака, аккаунтов),
распространение через подписанный + нотариально заверенный DMG с сайта
(НЕ App Store), лицензия MIT.

**Полная продуктовая спецификация находится у владельца проекта** (большой документ
на русском, ~20 разделов). Она НЕ лежит в репозитории — см. п. 4, задача D4:
положить её в `docs/SPEC.md`. Не начинать крупный функционал, не сверившись со
спецификацией у пользователя: там детально описаны состояния Dynamic Island,
приоритеты состояний, приватность, онбординг, план этапов 0–6.

## 3. Что уже реализовано в коде (и работает)

В `GlobalHotKey.swift`:

- Регистрация глобального хоткея ⌘⇧A через Carbon `RegisterEventHotKey`
  + `InstallEventHandler` с контекстом через `Unmanaged`.
- Проверка/запрос Accessibility (`AXIsProcessTrustedWithOptions` с prompt).
- Вставка текста в сфокусированное поле: сначала прямая запись через
  `kAXSelectedTextAttribute`, при неудаче — синтетические Unicode-события
  через `CGEvent` + `keyboardSetUnicodeString`.
- **Защита от зацикливания:** все синтетические события помечаются полем
  `.eventSourceUserData = 0x415A_41`, монитор их игнорирует. Это правильное
  решение — СОХРАНИ его.
- Отказ работать с secure-полями (`kAXSecureTextFieldSubrole`).
- Глобальный монитор `.keyDown` накапливает `currentWord`; по разделителю
  вызывает исправление; замена слова через установку
  `kAXSelectedTextRangeAttribute` + `kAXSelectedTextAttribute` с задержкой 30 мс.
- Ограничение прототипа: работает только когда frontmost-приложение — TextEdit
  (`com.apple.TextEdit`). Это сознательное ограничение («TextEdit-only proof»).

### Блок C — рефакторинг `GlobalHotKey.swift` (монолит из 4 ответственностей)

Целевая структура:

```
Aza/
  Core/
    TextInsertion.swift          // insert(), postUnicode(), markAndPost(), replaceTypedWord()
    SecureFieldDetector.swift    // isSecure(), isTextInput()
  Features/Layout/
    LayoutCorrectionEngine.swift // ЧИСТАЯ логика correction(for:) — без AX, тестируемая
    WordMonitor.swift            // NSEvent-монитор, накопление currentWord
  Features/HotKeys/
    HotKeyController.swift       // Carbon-регистрация хоткея
```

Ключевое требование: `correction(for:)` должен стать чистой функцией над словарём
соответствий (таблица раскладки QWERTY↔ЙЦУКЕН), а не `word == "ghbdtn" ? "привет" : nil`.

Конкретные баги, которые устранить при рефакторинге:

1. **Гонка при замене слова:** `finishWord()` читает выделение, ждёт 30 мс
   (`DispatchQueue.main.asyncAfter`) и затем сдвигает диапазон относительно
   СТАРОЙ позиции курсора. Если пользователь за эти 30 мс напечатал символы или
   нажал стрелку — замена испортит текст. Перед заменой перечитать
   `kAXSelectedTextRangeAttribute` и проверить, что курсор не сдвинулся.
2. **Force cast** `value as! AXUIElement` (~строки 107 и 204), `as! AXValue`
   (~245) → условные приведения (`as?`) с graceful fallback. Чужие приложения
   могут вернуть неожиданные типы — сейчас любой сброс уронит приложение.
3. **`deinit` в `@MainActor`-классе:** `NSEvent.removeMonitor` требует main
   thread, а `deinit` акторную изоляцию не гарантирует. Сделать явный `stop()`
   или удалять монитор с проверкой потока.
4. **Обработка Delete** (`currentWord.removeLast()`) не учитывает ⌘V, выбор
   текста, IME — задокументировать как известное ограничение прототипа.
5. **Accessibility-проверка только по нажатию хоткея** — проверять
   `AXIsProcessTrusted()` при старте и показывать статус в меню сразу
   (см. онбординг, раздел 9 спецификации).
6. Ошибку `registrationError: OSStatus` показывать человекочитаемо, а не сырым кодом.

## 6. Ограничения и правила (не нарушать)

- **Приватность — фундаментальный принцип:** никакого сетевого трафика кроме
  загрузки моделей/расписаний/обновлений; никакой телеметрии; аудио только в
  оперативной памяти; не логировать набираемый текст, транскрипты, буфер,
  координаты (раздел 12 спецификации).
- Никогда не вставлять текст в secure-поля, менеджеры паролей, терминалы,
  редакторы кода, поля URL/email (раздел 6.3 спецификации).
- Маркер синтетических событий `.eventSourceUserData` сохранять во всех новых
  путях ввода.
- Не включать в публичный MIT-репозиторий сторонние материалы с отдельными
  лицензиями (расписания ДУМ, звуки азана/природы, модели Whisper, словари) —
  раздел 15 спецификации.
- UI-язык общения с пользователем — русский; комментарии в коде допустимы на английском.
- Стиль: SwiftUI + AppKit, нативный macOS, никаких сторонних зависимостей без
  согласования (сейчас их нет вообще).
