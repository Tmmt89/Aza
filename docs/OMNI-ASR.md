# Чеченская диктовка

Настройки → Диктовка → **Чеченский · OmniASR → выбрать вариант → Скачать**. Затем удерживать
**⌃⌥D** для чеченской диктовки; **⌃⇧D** запускает Whisper. Оба сочетания
доступны одновременно и меняются в разделе «Запуск». Прежнее пользовательское
назначение Whisper сохраняется. Переключать язык для этих клавиш не нужно.
Без скачанной OmniASR её клавиша показывает сообщение о необходимой загрузке,
не открывая микрофон и не начиная скачивание.

Отпускание своей клавиши завершает запись и вставляет текст. Двойное нажатие
той же клавиши включает фиксацию; повторное нажатие, Пробел, Enter или кнопка
стоп завершают её. Клавиша другой модели не вмешивается в текущую запись.
Следующую диктовку можно начать после окончания распознавания и вставки текста.

Выбор языка в меню применяется к запуску кнопкой и к Whisper. Если выбран
«Чеченский», кнопка запускает OmniASR, а клавиша Whisper использует «Авто»
(русский / English). Клавиша OmniASR запускает выбранный в настройках вариант OmniASR.

Используются оригинальные веса Meta без дообучения, CPU, float32. Требуется Apple Silicon.

| Вариант | Веса | Управление распознаванием |
| --- | --- | --- |
| `omniASR_CTC_1B_v2` (по умолчанию) | 3,9 ГБ | Ограничение выходного алфавита; языковую подсказку CTC не принимает |
| `omniASR_LLM_1B_v2` | 9,1 ГБ | Подсказка `che_Cyrl` для каждого фрагмента и то же ограничение алфавита |

Перед выбором символов декодером Aza запрещает токены, содержащие буквы вне
русского и чеченского алфавита. Палочка `ӏ` / `Ӏ`, цифры, пробелы и обычная
пунктуация разрешены; blank, EOS и padding сохраняются. Это маска logits в
`final_proj`, а не удаление букв из готового ответа и не перевод.

Ограничение письма не гарантирует правильные чеченские слова. Для LLM задана
одна языковая подсказка — чеченская. Русские буквы разрешены, но качество
русских вставок и смешанной речи нужно проверять на записях носителей.
LLM требует больше памяти и времени; CTC остаётся быстрым вариантом по умолчанию.
Статус «Вставлено (OmniASR)» называет движок, а не обнаруженный язык.

## Установка и локальность

- Установка выбранного варианта начинается **только кнопкой**. Её можно отменить
  и повторить. Выбор варианта или его горячая клавиша ничего не скачивают.
- Aza скачивает Python standalone 3.12.14 (Astral, выпуск 20260901), затем
  фиксированные бинарные Python-пакеты с PyPI и веса с серверов Meta.
- SHA-256 архива Python, весов, токенизатора и пакетов проверяются до использования.
- Всё находится в `~/Library/Application Support/Aza/OmniASR`. Homebrew,
  системный Python и окружение из отдельного STT-демо не используются.
- `soundfile` содержит собственную libsndfile. Обучающий `kenlm`, который
  не импортируется CTC-пайплайном 0.2.0, исключён из установки.
- В metadata upstream 0.2.0 ошибочно указано `<=3.12`: pip отклоняет даже 3.12.14.
  При установке используется `--ignore-requires-python`; lock разрешён для 3.12,
  допустимы только бинарные колёса, после установки проверяется настоящая модель.
- Python, зависимости и токенизатор общие; у CTC и LLM отдельные веса и маркеры
  готовности. Маркер пишется только после настоящей загрузки выбранной модели.
  Уже скачанная CTC сохраняет готовность после обновления приложения.
- Кнопка «Удалить OmniASR» удаляет оба варианта вместе с общими компонентами.

Инференс получает mono float32 16 кГц через stdin и возвращает JSON через stdout.
Аудиофайлы и транскрипты в окружение модели не записываются. Сетевые соединения
в процессе распознавания запрещены; checkpoint и tokenizer загружаются по
локальным путям через API `load_custom_model` / `load_char_tokenizer`. Это
обходит ошибку fairseq2 0.6: загрузчик `file:` URI не декодирует `%20` в пробел,
из-за чего стандартная папка macOS `Application Support` не находилась.
Ни Gradio, ни HTTP-сервер не запускаются.

## Совместная работа с Whisper

У моделей разные папки, настройки и способы загрузки. Выбор профиля Whisper
сохраняется при переходе на чеченский. Язык и вариант OmniASR захватываются перед
записью; последующее изменение настроек не перенаправляет уже записанный звук.

Перед работой OmniASR Aza отменяет и дожидается загрузки/прогрева/стриминга Whisper,
освобождает его экземпляр. Возврат к Whisper ждёт завершения отменённого
OmniASR-процесса. Общие состояния диктовки запрещают две записи или установку
во время распознавания. Удаление дожидается завершения работы моделей.

Для каждой чеченской диктовки запускается один процесс. Он завершается после
получения текста, при отмене, блокировке экрана или закрытии Aza. Поэтому
настройка выгрузки по таймеру относится к Whisper. Цена простого жизненного
цикла — холодная загрузка OmniASR перед каждым распознаванием.

Записи до 30 минут разбиваются на фрагменты до 30 секунд с выбором тихой
границы между 20-й и 30-й секундами. Все сэмплы сохраняются в исходном порядке.
При непрерывной речи граница может попасть внутрь слова; следующим улучшением
по результатам проверки качества может стать VAD. Русско-английские фильтры
слов-паразитов, подсказки и фильтры уверенности Whisper к OmniASR не применяются.

## Проверка

`Tools/check.sh` запускает тесты приложения, включая отсутствие автозагрузки,
независимую готовность вариантов, передачу выбора и аудио через pipe, запрет
второго worker, отмену и следующий запуск.

Проверка разбиения аудио, маски алфавита и настоящей модели (после установки,
из корня репозитория; для LLM заменить последний аргумент на `llm`):

```sh
"$HOME/Library/Application Support/Aza/OmniASR/python/bin/python3" -I -B Tools/test_omni_asr.py \
  "$HOME/Library/Application Support/Aza/OmniASR" ctc
```

С аргументами проверяются SHA-256 выбранных файлов и настоящая загрузка модели
и токенизатора из пути с пробелами, кириллицей и символами `%`, `#`, `?`.
Повторная установка использует целые скачанные файлы; удалять их после ошибки
поиска пути не нужно.

Реальное распознавание нужно проверять дополнительно на чеченских записях
с эталоном носителя языка. Русская синтетическая фраза проверяет запуск и
декодирование, но не качество чеченской или смешанной речи.
