# План Этапа 2: буфер обмена

> Статус MVP: **ядро реализовано** (25.08.2026). Ниже — что готово,
> что осталось, и известные упрощения MVP.

## Готово

| Компонент | Реализация |
|---|---|
| Монитор | `PasteboardMonitor`: опрос changeCount каждые 0,5 с; пропуск Concealed/Transient/AutoGenerated типов; исключения менеджеров паролей (1Password, KeeWeb, LastPass); лимит длины |
| Хранилище | `ClipboardStore`: AES-GCM (CryptoKit), ключ 256 бит в Keychain (`WhenUnlockedThisDeviceOnly`); файл Application Support/Aza/clipboard-history.bin |
| Дедупликация | повторное копирование поднимает запись наверх с новой датой |
| Лимиты | 200 записей, 100 000 символов на запись |
| UI MVP | секция в меню-панели: тумблер сбора, последние 8 карточек (превью + источник + время), клик = копирование в системный буфер, очистка |
| Самопроверка | Debug-ассерты при старте: раундтрип, отсутствие plaintext на диске, игнор подменённого файла |

## Осталось (следующие инкременты)

1. Вставка записи прямо в активное поле через AX (сейчас: клик кладёт
   в системный буфер → пользователь жмёт ⌘V). Требует возврата фокуса
   в предыдущее приложение при закрытии панели.
2. Избранное (⌘D / звезда) — защита от автоочистки.
3. Поиск по истории.
4. Time-based retention из спецификации (сейчас лимит только по количеству).
5. Изображения, файлы, RTF (сейчас только plain text).
6. Quick Look превью для длинных записей.
7. Исключаемые приложения, настраиваемые пользователем (база уже есть
   в мониторе — нужен UI списка).
