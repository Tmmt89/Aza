# План Этапа 2: буфер обмена

> Статус MVP: **ядро реализовано** (25.08.2026). Ниже — что готово,
> что осталось, и известные упрощения MVP.

## Готово

| Компонент | Реализация |
|---|---|
| Монитор | `PasteboardMonitor`: опрос changeCount каждые 0,5 с; пропуск Concealed/Transient/AutoGenerated типов; исключения менеджеров паролей (1Password, KeeWeb, LastPass); лимит длины |
| Хранилище | `ClipboardStore`: AES-GCM (CryptoKit), локальный ключ 256 бит в `clipboard-history.key` (0600, каталог 0700), общий для Debug/Release; файл Application Support/Aza/clipboard-history.bin |
| Дедупликация | повторное копирование поднимает запись наверх с новой датой |
| Лимиты | 200 записей, 100 000 символов на запись |
| Избранное | звезда на карточке; переживает перезагрузку и автоочистку по объёму (self-test) |
| Поиск | живой фильтр по тексту, избранное сверху |
| Вставка в поле | клик по стрелке: панель скрывается → фокус возвращается → AX-вставка через 180 мс; secure-поля и не-текстовые элементы отсечены; буфер всегда обновлён как запасной путь |
| UI MVP | секция в меню-панели: тумблер сбора, поиск, карточки (превью + источник + время + звезда + вставка), очистка (избранное сохраняется) |
| Самопроверка | Debug-ассерты при старте: раундтрип, отсутствие plaintext на диске, игнор подменённого файла, сохранность избранного, порядок автоочистки (старые первыми), delete/restore |
| Пагинация | «Показать ещё (N)» — по 10 карточек за шаг |
| Удаление | контекстное меню карточки → «Удалить»; строка «Удалено · Отменить» видна 5 секунд, отмена возвращает запись на прежнее место |

| Retention | срок хранения (§8.8): пикер День/Неделю/Месяц/Год/Бессрочно, default месяц; избранное не устаревает; очистка при старте и каждом добавлении (включая дедуп) |
| Вставка везде | ролевой фильтр AX заменён функциональным isTextLike (читаемый selected range) — вставка/отмена работают в Notes/Electron; в кнопки синтетика не печатается |

## Сделано 26.08 (вечер)

| Компонент | Реализация |
|---|---|
| Виды записей | text / rtf / image / files / link; классификация в мониторе (fileURL → png/tiff → NSURL → rtf → URL-текст → текст); изображения нормализуются в PNG |
| Blob-хранилище | изображения в отдельных AES-GCM файлах `clipboard-history.blobs/<id>.bin`; blob пишется до метаданных, удаляется после; переживает окно «Отменить» (finalizeDelete); sweep сирот после успешной расшифровки; read-only-сессия blob-ы не трогает и не пишет |
| Лимиты §8.8 | 100 МБ на объект, 2 ГБ общий бюджет (по фактическим байтам, избранное — мягкий потолок) |
| Копирование по виду | files → NSURL, image → PNG, rtf → rtf+string; AX-вставка только для текстовых видов, остальное — «⌘V» |
| Асинхронный старт | чтение и перенос локального ключа идут в фоне (ClipboardStartup); обращений к Keychain нет |

## Сделано 27.08 (ночь)
